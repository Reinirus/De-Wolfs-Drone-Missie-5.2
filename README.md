# De Wolf’s Drone Missie Academie 5.2

Visuele infographic-weergave met vluchtkaart, telemetrie en mobiel robuuste aanraakbediening. De bestaande WebGL-vliegwereld, 10 missies, foto-opdrachten, scores, RTH en theorie zijn behouden.

De vijf referentie-infographics zijn gebruikt als ontwerpvoorbeeld, niet als tekst of interactieve achtergrond.
